I wanted Phera to feel like part of the server, so the features flow into each other.

01 · CONVERSATION

It talks like it was already in the chat.

Phera can reply automatically, jump in only when it has something useful to add, or wait for a mention. Recent conversation and saved details are pulled in when they actually matter, instead of being dumped back at you.

Memory can be inspected, corrected, switched off or cleared. The point is continuity, not creepiness.

02 · MUSIC

Drop a song. Phera handles the whole session.

I built the player for actual shared listening: search by song or artist, use Spotify catalogue data, match playable audio from supported sources, then keep the queue alive with controls, favourites, history, radio, lyrics and recaps.

You can seek, loop, replay, go back, shuffle, edit the queue, set a sleep timer and even correct a bad source match without leaving Discord.

03 · VOICE

Say “Phera” and the VC can answer back.

Phera can join voice, speak replies, switch between 25 voices and listen for a wake word before handling short addressed requests. Music controls stay hands-free too — skip, pause, replay, shuffle, volume, artist radio and more.

The bot only routes short addressed speech into the voice-command pipeline; ordinary VC chatter is ignored by design.

04 · PHERA CINEMA

A prompt can become a tiny film studio.

Phera Cinema turns an idea into a story, cast, dialogue, voices, shots and an edit. You can steer the look from live-action cinema to noir, anime, cyberpunk, fantasy, storybook or sci-fi, then choose widescreen, vertical or square delivery.

Video and score generation are enabled when the configured generation backends are available — the directing pipeline itself lives inside Phera.

05 · PHERA ARCADE

The chat can turn into a game room.

I built a public arcade with 20 playable games rendered straight into Discord. People can watch, jump into multiplayer rounds, use button or keyboard-style controls, earn persistent XP and chase achievements and leaderboards.

Snake, 2048, Connect Four, Blackjack, Maze, Word Grid, Battleship and the rest all run through the same live arcade system.

PHERA MODEL LAB · FROM SCRATCH

The next step is teaching Phera to run on a model I built myself.

Right now the Discord bot uses hosted AI models for its production intelligence. Separately, I'm building Phera's own transformer from the tokenizer up — dataset, architecture, pretraining, checkpoints and evaluation.

The current research build is Phera v0.2: a roughly 97.2M-parameter base model that has completed its first 245.76M-token pretraining run. It can produce language, but it still needs stronger base knowledge before proper instruction and personality tuning.
