PHERA / PRIVACY

Privacy Policy.

Phera processes only the Discord information needed to provide its features. This page explains the data the bot may access, how it is used, and the controls available to users and server administrators.

Effective 29 September 2026Contact: @prats__ on Discord
Important: Phera’s separately developed experimental language model is not trained on message content collected from Discord through the production bot.

1. Information Phera may process

Depending on which features are enabled and used, Phera may process:

  • Discord user, server, channel and message identifiers; display names; roles/permissions; timestamps and other Discord metadata needed to operate the bot.
  • Message content in channels where Phera chat/memory is enabled, plus limited recent channel history used to provide conversational context.
  • Attachment filenames and, when a feature needs them, image or media links supplied through Discord.
  • Channel summaries, saved user facts, shared channel notes and recent-message context used by Phera’s memory system.
  • Slash-command inputs and feature settings such as music, voice, chat-mode, moderation or game interactions.
  • Operational diagnostics and aggregate usage information needed to keep the bot functioning and troubleshoot problems.

2. Voice data

When voice features are enabled, audio may be processed transiently to detect the Phera wake word, transcribe an addressed request and generate a reply. Phera’s current design does not intentionally persist raw voice audio. A small amount of recent voice conversation context may exist temporarily in memory while the running process handles follow-up questions.

3. Why the information is used

The information above is used only as needed to provide Phera’s stated features: responding to users, maintaining opted-in conversational context and memory, playing or managing media, handling voice requests, performing moderation actions requested by authorised users, running games/tools, preventing abuse and maintaining the service.

4. Memory controls

Phera includes user and server controls for its persistent chat memory:

  • /memory shows your saved facts and the current channel context.
  • /memory-optout can stop future memory collection for you in the current channel while still allowing Phera to answer your current messages.
  • /forget-me clears your saved messages and facts from Phera’s chat memory.
  • Authorised server managers can use /memory-reset to clear a channel’s memory and can set the channel chat mode to off to stop chat/memory collection there.

5. Retention and deletion

Phera keeps persistent API data only while it is needed for the enabled features or until it is deleted. No fixed retention period is promised for persistent memory. Users can use the controls above or contact @prats__ on Discord to request access, correction or deletion. Data will also be removed when it is no longer needed to operate the relevant feature, when required by Discord, or if Phera stops operating.

6. Third-party processing

To provide requested features, Phera may send only the information needed for that feature to service providers. Depending on configuration, these may include hosting providers, AI or speech-processing providers such as Groq, music/catalogue or playback services such as Spotify and supported media sources, and search/image providers. Data is not shared with data brokers or advertising networks and Discord API data is not sold.

7. Model training

Discord message content obtained by the production bot is not used to train Phera’s separately developed custom language model. The model-development project uses separately sourced training material. This separation is intentional.

8. Security

Phera’s operator uses reasonable technical and administrative safeguards intended to protect Discord API data and developer credentials. Access to stored data is limited to what is needed to operate and maintain the bot. Users should never send passwords, authentication tokens or other secrets to Phera.

9. Children

Phera is not directed to anyone below Discord’s minimum permitted age. Users must meet Discord’s minimum age requirement in their country.

10. Your choices and contact

You can remove Phera from a server (if authorised), stop using the bot, use the memory controls above, or contact @prats__ on Discord for privacy requests, support or reports. Requests will be handled as reasonably and promptly as possible.

11. Changes

This Privacy Policy may be updated when Phera’s features, service providers or data practices change. The effective date at the top will be updated for material changes.
